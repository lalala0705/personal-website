# 个人网站

简约编辑式排版与自然摄影结合的个人网站。包含个人坐标、成长与实践、Vibe Coding、思考与创作、工作之外。成长路线与代表项目已合并：左侧自述，右侧按已提供的经历顺序倒叙展示可点击的经历卡片，详情按成果速览、角色与职责、能力成长、具体工作、可展开的代表实践与文档沉淀组织，洋葱学园区分北京与武汉的实践；五段任职时间均已由用户确认。

## 发布与同步

网站由 GitHub Pages 从 `main` 分支根目录发布。每次向 `main` 推送后，GitHub 自动更新在线网站，不需要手动重新上传。

在线地址：[个人网站](https://lalala0705.github.io/personal-website/)。

发布来源已配置为 `main` 分支的 `/ (root)`。可在仓库 Actions 中查看 `pages build and deployment` 的进度；发布成功后才代表在线版本已更新。

本仓库是后续网站内容和样式的主要来源。通过 Codex 修改后，应完成必要检查、提交并推送到本仓库；直接在 GitHub 编辑文件并提交到 `main` 也会自动发布。此配置不监听其他平台的独立修改，其他地方的改动需要先同步进本仓库。

## 文件

- `index.html`：页面结构与文案。
- `style.css`：桌面和手机布局。
- `app.js`：倒叙经历卡片、经历与项目详情、导航与照片弹窗。
- `content.js`：根据个人说明书整理的五站经历与案例初稿。
- `assets/`：摄影示意素材。

这是无构建步骤的静态网站。下载后打开 `index.html` 即可查看；所有资源路径兼容 GitHub Pages 项目子路径。
