# 网站标题字形

仅用于标题与少量手写点缀，正文和导航保持原来的系统字体。

- `bill-editorial.woff2`：Noto Serif SC，500 字重；标题所需字符子集。
- `bill-handwritten.woff2`：LXGW WenKai TC，400 字重；“不务正业”“好奇”和照片旁生活短句所需字符子集。
- 均由 Google Fonts 的公开 CSS API 提供，自托管以避免访客依赖外部字体请求；许可证见相应 OFL 文件。

字体许可为 SIL Open Font License 1.1，支持商业网站使用。新增标题文字时应重新生成对应子集；未包含的字符会使用回退字体。

字体来源：
- https://fonts.google.com/noto/specimen/Noto+Serif+SC
- https://fonts.google.com/specimen/LXGW+WenKai+TC
