# Bill 人偶动作素材

- `bill-avatar.png`：原始静态人偶，用于加载失败和减少动态效果时回退。
- `bill-actions.png`：透明背景 1536 × 1024 动作图，按四列两行等分，编号从左到右、从上到下为 0–7。
- 0 待机，1 闭眼，2 举杯，3 喝咖啡，4 放下杯子，5 左手伸出打招呼，6–7 左手挥动。

`assistant-motion.js` 使用原图的完整帧，不裁切或修改素材。每隔约 5–7.5 秒触发待机动作，第三次为喝咖啡。鼠标或键盘聚焦时优先打招呼；移开后复位。打开聊天、页面进入后台时暂停，并响应系统“减少动态效果”设置。

动作不调用 AI，也不影响点击打开聊天的原有逻辑。不要通过循环发送 AI 请求驱动动画。
