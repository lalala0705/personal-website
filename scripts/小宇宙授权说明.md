# 小宇宙账号授权

当前使用第三方项目整理的接口（参考 https://github.com/r266-tech/xiaoyuzhou），不是小宇宙官方 OAuth/MCP。此仓库中的授权辅助程序只与小宇宙官方 HTTPS 域名通信；不会将手机号、短信验证码和令牌发送到第三方 MCP 托管服务。

1. 在电脑上准备 Python 3。从本仓库 `scripts` 目录下载 `authorize-xiaoyuzhou.py` 和 `xiaoyuzhou-client.py`，放到同一文件夹。
2. 在该文件夹的终端运行 `python authorize-xiaoyuzhou.py`；Windows 也可运行 `py authorize-xiaoyuzhou.py`。
3. 输入已有小宇宙账号的手机号、短信验证码。验证码隐藏输入。若出现验证码挑战或要求注册，请停止，在官方客户端完成处理；辅助程序不处理注册。
4. 授权后会在个人目录 `.personal-website/xiaoyuzhou-token.json` 保存凭据。不要将此文件提交 Git、公开上传或发送到聊天中。
5. 在仓库 Settings → Secrets and variables → Actions → New repository secret，名称填写 `XIAOYUZHOU_TOKEN_JSON`，内容填入该文件的完整 JSON 文本。
6. Actions → Sync Xiaoyuzhou podcasts → Run workflow。订阅按关注时间倒序，最近单集每档取 3 条，跨节目合计展示最新 60 条。这里只读取订阅和节目元数据，不读取播放历史、评论或私信。

令牌轮换后保存在 GitHub Actions 加密缓存中；加密密钥从原始 Secret 派生，缓存不存明文凭据。不提供持续在线 MCP 服务，不把登录会话暴露给网站访客。缓存被清理、长时间失效或接口变更时，可能需要重新授权。当前为手动触发更新，没有开启定时任务。

撤销：在小宇宙中撤销对应登录（若账号设置支持），删除仓库 `XIAOYUZHOU_TOKEN_JSON` Secret 和 `xyz-credentials-` 缓存，并删除电脑上的授权文件。网站已发布的节目清单不会随凭据撤销自动删除，可另行清空 `data/podcasts.js`。
