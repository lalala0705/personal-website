# 小宇宙扫码授权（v3）

旧短信接口返回 404，v3 已替换为小宇宙账号服务扫码登录（参考 https://github.com/HuangYincan/VideoNote-MCP 的 CLI 实现）。这不是官方对外 OAuth/MCP 服务。已实测二维码创建接口返回 200；完整账号授权和订阅读取需要实际扫码后验证。

1. 解压授权工具，文件保持在同一个文件夹。打开该文件夹终端。
2. 安装二维码生成库：`python -m pip install qrcode==8.2`。从标准 Python 包索引安装，仅在本机生成二维码，不用在线二维码服务。
3. 运行 `python authorize-xiaoyuzhou.py`。浏览器会打开本机二维码文件，使用小宇宙 App 扫一扫，并在手机上确认登录。无需手机号或短信验证码。二维码约 3 分钟有效，不要上传或分享。
4. 成功后，个人目录 `.personal-website/xiaoyuzhou-token.json` 保存凭据。不要将此文件提交 Git、公开上传或发送到聊天中。
5. 在仓库 Settings → Secrets and variables → Actions → New repository secret，名称填写 `XIAOYUZHOU_TOKEN_JSON`，内容填入该文件的完整 JSON 文本。
6. Actions → Sync Xiaoyuzhou podcasts → Run workflow。订阅按关注时间倒序，最近单集每档取 3 条，跨节目合计展示最新 60 条。只读取订阅和节目元数据，不读取播放历史、评论或私信。

二维码保存在本机，结束或取消时删除。令牌轮换后保存在 GitHub Actions 加密缓存中；加密密钥从原始 Secret 派生，缓存不存明文。不提供持续在线 MCP 服务，不把登录会话暴露给网站访客。缓存被清理、长时间失效或接口变更时，可能需要重新授权。目前仅手动更新，没有定时任务。

错误提示只包含阶段和 HTTP 状态码或网络错误分类，不输出原始响应、二维码载荷或令牌。若接口拒绝请求，请停止，勿尝试绕过验证。

撤销：在小宇宙账号设置撤销对应登录（若支持），删除仓库 `XIAOYUZHOU_TOKEN_JSON` Secret 和 `xyz-credentials-` 缓存，并删除本机授权文件。网站已经发布的节目清单可以另行清空 `data/podcasts.js`。
